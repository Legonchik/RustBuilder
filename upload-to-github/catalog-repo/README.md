# Каталог баз RustBuilder

Публичный каталог схем построек для оверлея **RustBuilder**. Приложение скачивает `index.json` и файлы из `bases/`.

## Как выложить свою базу

**Из приложения:** «Базы» → выбери свою базу → «Выложить в каталог». Откроется GitHub с готовым файлом:
1. Войди в GitHub (если ещё не вошёл).
2. Нажми **Propose changes** / **Commit changes**, затем **Create pull request**.
3. Робот проверит файл. После одобрения база появится в каталоге (обычно через пару минут).

**Вручную:** форкни репозиторий, положи `.json` в папку `bases/` и открой pull request.

## Правила
- Один файл = одна база, не больше 100 КБ.
- `name` — до 60 символов, `description` — до 300.
- Поле `author` необязательно: если его нет, автором будет тот, кто добавил файл.

## Для владельца репозитория
- `index.json` собирается автоматически (GitHub Actions) при каждом изменении в `bases/` на ветке `main`.
- Проверить локально: `node scripts/build-index.mjs --check`.
